Auto pilot controls zoom, rotation, Swirl rate, evolution, curve parameters, Warp, Edge weave, and ring settings. Stop it to edit those values. Fractal mode, depth, repetitions, and symmetry stay adjustable.

A gentle swirl, then back to petals. Positive starts clockwise; negative starts counterclockwise. Zero or Pause camera holds the pulse. Twist never builds up.

Size sets thickness; frequency sets the travel and repeat rate. Velocity: +1 outward, 0 stationary, −1 inward.
